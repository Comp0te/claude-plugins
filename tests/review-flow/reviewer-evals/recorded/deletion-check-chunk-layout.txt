```

-    throw new ForbiddenError(`${actor.id} lacks admin role`);
-  }
```

- **Lost.** `deleteUser`/`deleteUsers` is the only place in the tree that ever checked `actor.roles`. I grepped the whole source tree for `roles.includes`, `isAdmin`, `authorize`, and `middleware` and found nothing — there is no other authorization layer (`src/routes/users.ts` calls straight through to `deleteUsers` with no check of its own). `ForbiddenError` is still exported from `src/errors.ts:1` but is never thrown anywhere in the current tree (`grep -rn "ForbiddenError"` → only the definition and the now-dead old import).
