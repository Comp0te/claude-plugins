file: src/pricing/orderTotal.ts:24

issue: No test checks an order whose subtotal is exactly `THRESHOLD` (100). The "just under" test (`tests/orderTotal.test.ts:12-14`) uses 99 and the "just over" test (`:20-22`) uses 101, so the comparison operator itself is never tested.
